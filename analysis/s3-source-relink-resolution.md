## 판정 근거

### 송파한양2차

- 제2024-178호 URL: https://urban.seoul.go.kr/view/html/PMNU2040000000?noticeCode=11000NTC202404180001
- 로컬 텍스트: `data/urban/text/files/17-11000NTC202404180001-17-11000NTC202404180001-notice_file-서울특별시_제2024-178호_고시.txt`
- 정보몽땅 사업개요: https://cleanup.seoul.go.kr/cafe/mastr-cleanup-bsnsSumry/execute.do?cafeId=710900000132y43&stepSeCode=102&div=sumry

제2024-178호는 가락아파트지구 개발기본계획 결정(변경) 고시다. 한양2차는 존치 대상으로 언급되며, 용적률 표에서 제3종일반주거지역 주택용지 230% 이하가 판독된다. 따라서 용적률 230%는 사업별 직접 인가값이 아니라 상위계획 기준값으로 확정한다.

층수는 정보몽땅 사업개요에서도 `지상:/지하:`로 비어 있고, 제2024-178호 OCR·이미지에서 송파한양2차 직접 층수값이 확인되지 않는다. 자동 재연결 큐에서 반복하기보다 사업시행계획/건축심의/공개항목에서 값이 나타날 때 재개한다.

### 대림가락

- 제2021-551호 URL: https://urban.seoul.go.kr/view/html/PMNU2040000000?noticeCode=11000NTC202111260001
- 로컬 텍스트: `data/urban/text/files/19-11000NTC202111260001-19-11000NTC202111260001-notice_file-서울특별시_2021-551호_고시.txt`
- 정보몽땅 사업개요: https://cleanup.seoul.go.kr/cafe/mastr-cleanup-bsnsSumry/execute.do?cafeId=710900000854k71&stepSeCode=102&div=sumry

대림가락 최고높이 129m는 제2021-551호 원문 이미지 검수에서 `해발고도 129m 이하 / 최고35층 이하`로 직접 확인된다. 정보몽땅 사업개요도 최고높이 129m를 표시하므로 S3-0030은 confirmed로 닫는다.

### 한양연립

- 정보몽땅 사업개요: https://cleanup.seoul.go.kr/cafe/mastr-cleanup-bsnsSumry/execute.do?cafeId=215900001126x73&stepSeCode=102&div=sumry
- 오연결 고시 URL: https://urban.seoul.go.kr/view/html/PMNU2040000000?noticeCode=11000NTC202407080004
- 오연결 로컬 텍스트: `data/urban/text/files/25-11000NTC202407080004-25-11000NTC202407080004-notice_file-서울특별시_제2024-282호_고시.txt`

제2024-282호는 구의·자양재정비촉진지구 자양1재정비촉진구역 변경 고시다. 한양연립 일대 가로주택정비사업의 직접 면적·용적률·건폐율·층수·높이·세대수 원문으로 사용할 수 없다.

다만 정보몽땅 사업개요는 한양연립 사업장 자체의 공식 사업개요로 다음 값을 직접 표시한다.

| 필드 | 정보몽땅 값 |
| --- | --- |
| 정비구역 면적 | 9,877.8㎡ |
| 건폐율 | 32% |
| 용적률 | 249% |
| 최고높이 | 43m |
| 층수 | 지상15층/지하2층 |
| 총 세대수 | 176 |

따라서 S3-0031~S3-0035는 `2024-282 오연결 제외 + 정보몽땅 공식 사업개요 보조값 연결`로 닫는다. S3-0036의 고시번호 2024-282는 한양연립 직접 고시번호가 아니므로 값으로 쓰지 않고, 직접 사업시행/조합설립 인가 고시번호 확보 전까지 deferred로 둔다.
