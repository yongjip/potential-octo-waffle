## 원문 판독

제2015-401호 고시는 제목부에 `서울특별시고시 제2015-401호`와 `2015년 12월 17일`을 표시한다. 정비사업 위치 및 면적은 송파구 잠실동 101-1번지 일대, 120,354㎡로 확인된다.

건축시설계획 표는 잠실우성아파트 주택재건축 정비구역의 공동주택 획지1을 다음처럼 제시한다.

| 항목 | 고시값 |
| --- | --- |
| 획지1 면적 | 111,188㎡ |
| 건폐율 | 25% 이하 |
| 정비계획 용적률 | 240% 이하 |
| 예정 법적상한 용적률 | 291.26% 이하 |
| 높이/최고층수 | 105m 이하, 최고35층 이하 |
| 총 세대수 | 2,716세대 |
| 소형주택 | 390세대 |

정비사업 시행계획 표는 현황 1,842세대, 계획 2,716세대, 증가 874세대를 표시한다. 정보몽땅 사업개요의 현재 요약값인 건폐율 23%, 지상49/지하4, 용적률 300%는 2015년 정비구역 지정 고시값과 다르므로 최신 사업개요값과 2015년 고시 계획값을 같은 단일값으로 병합하지 않는다.
