## 원문 판독

제2018-399호 고시는 서울시보 제3495호 2018. 12. 6.(목)에 수록되어 있으며, 제목부에 `서울특별시고시 제2018-399호`와 `2018년 12월 6일`을 표시한다.

정비구역 위치 및 면적 조서는 상가부지 제척에 따른 변경 후 정비구역 면적을 28,793㎡로 표시한다. 같은 페이지의 용도지역 결정 조서도 변경 후 제3종 일반주거지역 28,793㎡를 표시한다.

건축시설계획 변경 표는 다음 값을 제시한다.

| 항목 | 제2018-399호 변경고시 값 |
| --- | --- |
| 대지/획지 | 구역 28,793.0㎡, 획지1 25,456㎡ |
| 건폐율 | 50% 이하 |
| 용적률 | 정비계획 250% 이하, 예정 법정상한 299.99% 이하 |
| 높이/층수 | 최고 35층/110m 이하 |
| 주택공급계획 | 합계 725세대, 60㎡ 이하 280세대, 60~85㎡ 이하 260세대, 85㎡ 초과 185세대 |
| 소형주택 | 96세대 |

적용 용적률 산정 표는 기준용적률 210%, 허용용적률 230%, 개발가능용적률 265.76%, 정비계획용적률 250.0%, 법적상한용적률 299.99%를 분리해 제시한다. 따라서 비교표의 대표 `300%`는 정보몽땅 최신 사업개요의 반올림 대표값으로 유지할 수 있지만, 고시 원문값을 해석할 때는 정비계획/허용/법적상한 기준을 분리해야 한다.

정보몽땅 사업개요 원본 HTML은 건축계획 표에서 대지면적 25,456㎡, 건축면적 4,608㎡, 연면적 146,423㎡, 건폐율 2, 용적률 300, 최고높이 109, 지상35/지하4층을 표시한다. 건폐율 2는 건축면적/대지면적 계산값 약 18.1%와 맞지 않으므로, 원문 표시값은 확인하되 실제 해석에는 사업시행계획서 또는 후속 인허가 원문 확인이 필요하다.

정보몽땅 사업개요의 주택공급계획 분양 표는 165/262/199세대 합계 626세대를 표시한다. 이는 2018 변경고시의 주택공급계획 합계 725세대 및 같은 고시의 정비사업 시행계획 표상 계획 755세대와 다르므로, 최신 사업개요값과 2018 정비계획 고시값을 시점별로 나눠 기록한다.

정보몽땅 추진경과는 다음 단계일을 공개한다.

| 단계 | 추진경과 표시 |
| --- | --- |
| 추진위원회 승인 | 2016-01-26 `(변경)승인`, 동의율 80.64% |
| 조합설립인가 | 2017-01-17 `(변경)인가`, 동의율 97.68. 이후 2018-05-21부터 2026-05-06까지 변경인가 다수 |
| 사업시행인가 | 2022-09-08 `(변경)인가`, 2022-09-16 `(변경)인가고시`, 동의율 100 |
| 관리처분인가 | 추진경과 구간은 있으나 공개 항목 없음 |

따라서 `조합설립인가일`은 추진경과상 첫 인가일 2017-01-17로 쓸 수 있지만, 표시가 `(변경)인가`이므로 엄밀한 최초 원인가일 확인은 별도 인가 공문 또는 자치구 원문 확보 과제로 남긴다. `단계 공개 동의율`은 현재 사업시행인가 단계의 추진경과 공개 동의율 100으로 기록한다.
