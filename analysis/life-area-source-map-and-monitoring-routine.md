# 생활권 출처 지도와 모니터링 루틴

작성 기준: 2026-06-24 KST

이 문서는 강남, 잠실/송파, 구의/광진을 생활권 단위로 추적할 때 `어느 공식 출처를 먼저 열고`, `무슨 변화가 나오면`, `어느 로컬 문서를 먼저 고칠지`를 한 장으로 고정한 실행판이다. 기사 스캔용이 아니라 공식 원문 기반 최신 확인 루트만 남긴다.

## 공통 원칙

1. 생활권 촉매는 `context`, 사업 단계와 수치는 `primary`로 분리한다.
2. 고시번호, 고시일, 원문 URL, 첨부 파일명, 기준일 중 최소 2개가 확인돼야 확정값으로 승격한다.
3. 변화가 확인되면 `사업 메모 -> 생활권 비교 문서 -> 주간 로그` 순서로 반영한다.
4. 같은 신호라도 `생활권 상방`과 `개별 사업 단계`를 섞지 않는다.

## 루틴

### weekly

1. 생활권별 `context` 페이지 수정일 확인
2. 각 생활권 대표 사업 `primary` 페이지 단계/공개항목 확인
3. 자치구 고시공고와 서울도시공간포털 신규 고시 후보 확인
4. 변동 없으면 `no material change`, 변동 있으면 해당 사업 메모부터 수정

### monthly

1. 교통·도시계획 맥락 페이지 재확인
2. 실거래·시장 보조지표 갱신
3. 현장 답사 메모 미입력 생활권 우선 보강

### event-driven

- 외부 회신 도착
- 사업시행인가/관리처분인가/착공 신호 발생
- 대형 교통통제 또는 도시계획 고시 발표
