# 생활권 최신 공식 확인 가이드

작성 기준: 2026-06-24 KST

이 문서는 강남, 잠실/송파, 구의/광진을 생활권 단위로 다시 볼 때 어디서 최신 공식 변화를 먼저 확인해야 하는지 고정한 가이드다. 기사 스캔용이 아니라, 매주 또는 변화가 의심될 때 바로 열 공식 URL과 그 변화가 실제 판단 신호인지 구분하는 용도다.

## 공통 규칙

1. `수정일`, `고시일`, `고시번호`, `원문 URL`, `첨부 파일명`, `기준일` 중 최소 2개 이상이 확인될 때만 비교표에 반영한다.
2. 서울시 정책 페이지는 생활권 촉매 `context`로 쓴다. 사업 단계와 수치는 도시공간포털, 정보몽땅, 자치구 고시공고, 공식 회신으로만 올린다.
3. 변화가 나오면 `사업 메모 -> 생활권 비교 문서 -> 주간 로그` 순서로 고친다.
4. 생활권마다 `context 확인 -> 대표 사업 primary 확인 -> 자치구/서울시 추가 고시 확인` 순서로 본다.
