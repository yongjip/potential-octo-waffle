## 원문 판독

제2025-278호 고시는 `도시관리계획[용도지구: (종전)아파트지구] 및 잠실아파트지구 정비계획(개발기본계획) 결정(변경)` 고시다. 제목부에는 `서울특별시고시 제2025-278호`와 `2025년 05월 22일`이 표시된다.

토지이용계획 총괄표는 변경 후 주택용지 비고에 `존치 장미1, 2, 3차`를 표시한다. 이는 장미가 이번 아파트지구 제척 이후에도 존치되는 범위에 해당한다는 맥락이지, 장미 개별 정비사업의 건축시설계획 확정값은 아니다.

건축물 관련계획은 다음처럼 지구 일반 규칙을 제시한다.

| 항목 | 고시값 | 해석 |
| --- | --- | --- |
| 건폐율 규제 | 제1·2종 일반주거지역 60% 이하, 제3종 일반주거지역 50% 이하 | 장미 직접 건폐율이 아니라 용도지역별 일반 상한 |
| 용적률 규제 | 제3종 일반주거지역 계획용적률 230% | 직접 사업 용적률이 아니라 지구 규칙 |
| 건축물 높이 | 제1종 4층 이하, 제2종 7층 이하, 제3종 층수제한 없음 | 장미 직접 층수/최고높이 아님 |
| 사업시행 반영사항 | 정비계획에서 결정하지 않은 사항은 향후 시행단위별 사업시행인가 시 반영 | 개별 사업 직접 원문 필요 |

따라서 S5-0055~S5-0058은 확정 수치로 채우지 않는다. 장미의 건폐율, 층수, 최고높이, 총 세대수는 사업시행계획서, 건축위원회 심의 결과, 또는 장미 직접 정비계획 변경고시 원문에서 다시 확인해야 한다.
