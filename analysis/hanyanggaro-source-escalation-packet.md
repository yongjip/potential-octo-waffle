# 한양연립 원문 확인 패킷

작성 기준: 2026-06-24 KST

이 문서는 `한양연립 일대 가로주택정비사업`의 단계 불일치 병목을 외부 확인 단위로 고정한 실행 메모다. 목적은 `사업시행인가`를 `착공`으로 임의 승격하는 것이 아니라, `착공 신고 필 2024-02-15`를 직접 잠글 수 있는 공식 문서명, 보유부서, 공개 경로를 확인하는 것이다.

## 한줄 요약

- 광진구 직접 고시 원문은 `사업시행인가` 축을 잠근다.
- 정보몽땅 추진경과와 서울도시공간포털 사업구역 레이어는 `착공` 선행 신호를 준다.
- 정보몽땅 비회원 공개 경로만으로는 `착공신고` 직접 원문이 닫히지 않는다.
- 다음 액션은 `광진구 정보공개청구`를 1순위로, `광진구 주거사업과`와 `정보몽땅 문의처`를 보조 경로로 쓰는 것이다.

## 현재 공식 상태

| 항목 | 값 |
| --- | --- |
| 사업명 | 한양연립 일대 가로주택정비사업 |
| 관할 | 광진구 |
| 비교표 현재 단계 | 사업시행인가 |
| 착공 쪽 공식 신호 | 정보몽땅 추진경과 `착공 신고 필 2024-02-15`; 예정공정표 `착공`; 공사기간 `2024.02.26 ~ 2026.08.25` |
| 직접 고시 축 | 광진구 제2023-115호, 제2023-4호, 제2024-372호, 제2024-449호 |
| 공개 병목 | `착공신고` 직접 원문, `제2022-158호` 원문, 정보몽땅 `공사시행` 비회원 실자료 |
| 핵심 메모 | `presentSn`는 `recordCode` 대체 경로가 아니고, `공사시행` 공개항목도 비회원 원문을 직접 주지 않는다. |

- 연구 파일에는 개별 직원 이름·직통 연락처를 복사하지 않는다.
- 값 확정은 회신의 `고시번호`, `고시일`, `원문 URL`, `첨부명`, `보유부서`, `공개/부분공개/비공개 사유`가 확보된 뒤에만 한다.
- 정보몽땅 헬프데스크는 시스템/권한 경계 확인용이다. 사업 수치 확정 근거로 쓰지 않는다.

## 요청해야 할 자료

1. `착공 신고 필 2024-02-15`를 직접 설명하는 공식 문서명
2. 해당 문서의 원문, 첨부, 공개 URL 또는 열람 경로
3. 전자공개가 안 되면 보유부서, 공개/부분공개/비공개 사유, 방문열람 가능 여부
4. `광진구 제2022-158호` 사업시행계획인가 원문 또는 첨부
5. `사업시행계획서(인가)` 본문 PDF 또는 공개 가능한 별첨
6. 정보몽땅 `공사시행` 소분류 `216`, `217`, `218`의 비회원 미노출 사유

```text
[정보공개청구] 한양연립 일대 가로주택정비사업 착공신고 관련 원문 및 사업시행계획인가 자료 공개 요청
```

## 접수 본문 초안

```text
안녕하세요.

한양연립 일대 가로주택정비사업의 공식 원문 확인을 위해 아래 자료 공개를 요청드립니다.

사업명: 한양연립 일대 가로주택정비사업
관할/단계: 광진구 / 사업시행인가(공개 진행경과상 착공 신고 필 2024-02-15 확인)

확인 요청 자료
1. 정보몽땅 추진경과에 표시된 `착공 신고 필 2024-02-15`를 직접 설명하는 문서의 자료명, 원문, 첨부, 고시번호 또는 접수/처리 식별정보
2. 위 착공 관련 문서가 전자공개 가능한 경우 공식 URL 또는 파일
3. 광진구 제2022-158호 사업시행계획인가 고시문 또는 해당 인가문 본문/첨부
4. 한양연립 일대 가로주택정비사업 사업시행계획서(인가) 본문 또는 공개 가능한 별첨
5. 정보몽땅 비회원 공개화면에서 `공사시행` 항목이 식별되지만 실자료가 열리지 않는 경우, 공개 가능 경로와 비회원 미노출 사유
6. 전자파일 공개가 어려운 경우 자료명, 보유부서, 공개/부분공개/비공개 사유, 방문열람 가능 여부

현재 공개 확인 결과는 다음과 같습니다.
- 광진구 직접 고시 원문으로는 제2023-115호(2023-12-07 사업시행계획변경인가), 제2023-4호(2023-01-12 사업시행계획인가 정정), 제2024-372호(2024-03-25 건설공사 안전점검 수행기관 지정 모집공고), 제2024-449호(2024-04-09 건설공사 안전점검 수행기관 지정 결과)를 확인했습니다.
- 제2024-372호 첨부 예정공정표에는 작성일 2024.02.16, 공사기간 2024.02.26 ~ 2026.08.25, `착공` 마일스톤이 표시됩니다.
- 정보몽땅 추진경과에는 `착공 신고 필 2024-02-15`가 표시됩니다.
- 그러나 정보몽땅 비회원 공개 경로에서는 `공사시행` 항목의 소분류 216 월별공사진행사항, 217 사업비변경내역(공사비 제외), 218 공사비변경내역이 식별되더라도 실자료는 열람되지 않았습니다.
- 서울도시공간포털 사업구역 레이어에서는 `착공` 단계가 보이지만, 팝업 hidden `recordCode`가 비어 있어 직접 고시 원문으로 연결되지 않았습니다.

위 자료는 공개 요약값을 확정값으로 쓰기 전에 공식 원문·문서명·보유부서를 확인하기 위한 용도입니다.
가능하면 전자파일, 공개 URL, 고시번호·고시일, 자료명, 기준일을 함께 알려주시기 바랍니다.

감사합니다.
```
