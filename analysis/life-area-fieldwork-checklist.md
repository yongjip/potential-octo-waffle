# 생활권 현장 체크리스트

작성 기준: 2026-06-24 KST

이 문서는 강남·잠실/송파·구의/광진 생활권 답사를 실제로 나가기 직전에 여는 실행용 체크리스트다. `fieldwork-route-planner`가 전체 노선표라면, 이 문서는 지금 당장 걸어볼 핵심 루트와 기록 항목만 남긴다.

## 사용 원칙

1. 답사 전에는 반드시 해당 사업의 공식 원문과 현재 단계 메모를 먼저 읽는다.
2. 현장 기록은 "좋다/나쁘다"가 아니라 기존 공식 가설을 유지·보류·하향할 근거를 남기는 방식으로 적는다.
3. 답사 직후 `data/review/fieldwork-observations.json`에 넣고, 바뀐 해석은 사업 메모와 `analysis/transport-location-context.md`까지 반영한다.

## 공통 기록 항목

| 항목 | 확인 기준 |
| --- | --- |
| 역 접근 | 실제 출발 역/출구, 체감 보행시간, 고저차 |
| 횡단 대기 | 큰 도로·교차로·신호대기 시간 |
| 단절 | 한강, 탄천, 올림픽대로, 강변북로, 대로변 담장, 상가 블록 단절 |
| 출입구 | 단지 정문/후문, 보행 동선, 차량 동선 충돌 |
| 상권/혼잡 | 출퇴근/행사/학원가/터미널 혼잡 |
| 생활편의 | 학교, 공원, 한강공원, 버스환승, 생활상권 연결 |
| 공사/사업 신호 | 현수막, 공고문, 이주/철거/시공 관련 현장 신호 |
| 해석 | 장기 가능성, 리스크, 확신도 변화 |

## 1. 잠실/송파 핵심 루트

### 대상

- `잠실5단지`
- `잠실우성4차`

`잠실역 -> 잠실5단지 외곽 -> 잠실우성4차 -> 잠실나루역 방향 -> 장미1,2,3차 -> 한강 접근부`

- 잠실역 환승 강도와 실제 보행 피로도가 예상보다 큰가.
- 잠실 MICE 기대를 감안해도 한강·탄천·대형도로 단절이 생활권 체감을 깎는가.
- `잠실우성4차`는 관리처분 이후 사업 속도 프리미엄이 입지 혼잡을 상쇄하는가.

- [ ] 잠실역 주요 출구 1개 이상에서 각 사업 경계까지 실제 보행시간 기록
- [ ] 잠실역 환승통로, 행사 인파, 대형상권 혼잡 여부 기록
- [ ] 잠실우성4차 주변 간선도로 횡단 대기와 단지 경계 접근 난이도 기록
- [ ] 장미1,2,3차에서 잠실나루역 접근, 한강공원 접근, 올림픽대로 단절 체감 기록
- [ ] 공사, 이주, 관리처분, 시공 관련 현장 표지나 현수막 확인
- [ ] `confidence_change`를 `up/flat/down` 중 하나로 명시

## 답사 후 10분 정리 규칙

3. 생활권 전체 해석이 바뀌면 `focus-area-comparison-brief`와 `transport-location-context` 수정
4. 공식 원문과 충돌하는 현장 인상은 감상으로 쓰지 말고 보류 메모로 남김
