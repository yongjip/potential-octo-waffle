# 핵심 사업 쌍 비교 템플릿

작성 기준: 2026-06-24 KST

이 문서는 같은 날 두 사업을 보고 바로 비교 메모를 남기기 위한 템플릿이다. 개별 현장 입력이 `사업 1건` 기준이라면, 이 문서는 `A와 B를 왜 다르게 읽어야 하는가`를 한 장에서 정리하는 용도다.

## 먼저 고를 비교 조합

| 조합 | 왜 묶나 | 핵심 비교 질문 |
| --- | --- | --- |
| 잠실우성4차 vs 장미1,2,3차 | 같은 잠실축 안에서 `단계 프리미엄`과 `보행/한강 체감`을 분리하기 좋다 | 관리처분 이후 속도 프리미엄이 실제 혼잡·단절을 이기는가 |
| 압구정3 vs 한양연립 | `상급지 프리미엄`과 `입지 보완형 소규모정비`를 가장 선명하게 대비할 수 있다 | 좋은 입지의 무거운 조건과 약한 사업의 좋은 접근 중 무엇이 더 설득력 있는가 |
| 잠실우성4차 vs 압구정3 | 둘 다 상방 스토리는 강하지만 리스크 구조가 다르다 | 하나는 비용·이주, 다른 하나는 공공기여·규제인데 어느 쪽이 더 무거운가 |

## 사용 순서

1. 비교할 두 사업을 고른다.
2. 각 사업의 개별 현장 입력을 먼저 넣거나, 최소한 메모를 따로 적어둔다.
3. 아래 템플릿에 `공식 원문`, `현장 체감`, `보조 시장 신호`를 분리해서 적는다.
4. 결론은 `누가 더 좋다`보다 `무엇이 더 무겁고 무엇이 더 아직 안 닫혔는가` 중심으로 적는다.
