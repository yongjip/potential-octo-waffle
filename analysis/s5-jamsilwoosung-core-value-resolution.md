## 원문 판독

고시 제목부에서 `서울특별시고시 제2015-401호`와 `2015년 12월 17일`이 직접 확인된다.

정비구역 면적은 고시 초반 결정조서에서 `송파구 잠실동 101-1번지 일대`와 `나. 면 적 : 120,354㎡`로 확인된다. 정보몽땅 사업개요의 120,354.2㎡는 같은 면적을 소수점 한 자리까지 구조화한 값으로 보고 precision split으로 기록한다.

건축계획 표는 `공동주택 및 부대복리시설 25 이하 240 이하 291.26 이하 105m이하, /최고35층이하`를 보여준다. 따라서 최고높이 105m은 직접 확정 가능하지만, 건폐율 23%, 층수 `지상:49/지하:4`, 용적률 300%는 현재 사업개요 대표값과 2015년 고시 계획값이 서로 다른 기준 또는 정의로 보아야 한다.

용적률 산정 문맥은 `개발가능용적률 = 210% + 10% + 20.5% = 240.5% ≒ 240%`와 `연면적 323,845.23㎡ / 부지면적 111,188㎡ = 291.26%`를 함께 보여준다. 정보몽땅 대표값 300%는 고시 단일값으로 직접 떨어지지 않으므로 summary 대표값과 notice 계획값을 분리 기록한다.

총 세대수는 `정비사업 시행으로 증가예상 세대수` 표에서 `현황 : 1,842세대`, `계획 : 2,716세대`, `증) 874세대`가 직접 확인된다. 대표 총 세대수는 계획값 2,716세대로 채우고, 현황/증가분은 메모에 같이 둔다.
