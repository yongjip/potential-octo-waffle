# Open Data Governance

작성 기준: 2026-06-24 KST

이 문서는 개인 knowledge base를 장기적으로 open data로 전환할 때의 공개 기준이다.

## 공개 기본값

비공개가 기본값이다. 공개는 별도 export 계층에서 만든다.

공개 후보:

- 공식 출처명, URL, 기준일, 수집일.
- 공개 원천에서 파생한 정규화 수치.
- 출처 링크가 붙은 factual assertion.
- 스키마, 코드북, 수집 방법론.

비공개 기본값:

- 개인 투자 판단, 매수/매도/비중 메모.
- 계정, API key, 접수번호와 연결된 개인정보.
- 정보공개 회신 전문 중 공개 범위가 불명확한 내용.
- 현장 답사 중 개인 위치/동선/사진 원본.
- LLM 중간 추론, 미검증 가설, 임시 점수.

## 공개 전 체크리스트

- 출처 라이선스가 재배포를 허용하는가.
- 원문을 그대로 재배포해도 되는가, 아니면 링크와 메타데이터만 가능한가.
- 개인정보, 연락처, 계정 정보, 접수번호가 제거됐는가.
- 기준일, 수집일, 생성일이 분리돼 있는가.
- factual data와 개인 analysis가 분리돼 있는가.
- 공개 데이터에 필요한 컬럼 설명과 단위가 있는가.
- LLM이 만든 값은 공식 출처 확인 없이 factual field에 들어가지 않았는가.

## 공개 산출물 권장 구조

```text
public/
  README.md
  datasets/
    <domain>/
      dataset-metadata.json
      rows.csv
      codebook.md
  sources/
    source-registry.csv
  methodology/
    collection-notes.md
```

`public/`은 아직 만들지 않는다. 공개할 데이터셋이 정해졌을 때 export 스크립트로 생성한다.

## 라이선스 판단

출처별 라이선스가 다르면 가장 제한적인 조건을 따른다. 라이선스가 불명확하면 raw 파일 공개 대신 출처 링크, 수집일, 정규화 스키마만 공개 후보로 둔다.

## 금융 데이터 주의

주식 도메인의 가격, 재무, valuation 데이터는 투자 조언이 아니다. 공개 데이터에는 계산 방법과 기준일을 붙이고, 개인 판단이나 포트폴리오 상태는 포함하지 않는다.
